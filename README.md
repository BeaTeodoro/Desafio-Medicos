# 🩺 Desafio Médicos

Aplicação frontend desenvolvida com **React + Vite**, focada na construção de uma interface moderna, responsiva e organizada para um projeto institucional voltado à promoção de saúde e incentivo ao voluntariado.

Este projeto faz parte do meu **portfólio profissional**, com o objetivo de demonstrar habilidades técnicas em **desenvolvimento frontend**, **componentização**, **organização de código** e **boas práticas de mercado**.

---

## 🔎 Visão Geral do Projeto

O **Desafio Médicos** simula uma plataforma institucional que apresenta iniciativas de saúde e ações sociais, com navegação clara e estrutura escalável.

O desenvolvimento foi guiado por princípios como:
- Separação de responsabilidades
- Reutilização de componentes
- Organização de pastas e arquivos
- Clareza e legibilidade do código
- Experiência do usuário (UI/UX)

## 🗂️ Estrutura do Projeto

```bash

├── assets/              # Imagens e arquivos estáticos
├── components/          # Componentes reutilizáveis
│   ├── header/
│   └── footer/
├── pages/               # Páginas da aplicação
│   ├── home/
│   └── sejaVoluntario/

├── main.jsx             # Ponto de entrada da aplicação
```
